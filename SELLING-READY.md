# GreenScore Product Line

This workspace now contains three separately packaged GreenScore variants:

- `greenscore-basic` - frontend-only starter version
- `greenscore-pro` - React + Express version with charts
- `greenscore-premium` - React + Express + MongoDB version with authentication

## Sellable Deliverables

Each version includes:

- source code
- README with setup instructions
- package lockfiles
- environment examples where needed
- no bundled `node_modules`
- no bundled production `dist`

## Suggested Positioning

### GreenScore Basic

- Best for students, beginners, and fast demo buyers
- Lowest setup complexity

### GreenScore Pro

- Best for clients who want a real dashboard and API
- Good balance between value and simplicity

### GreenScore Premium

- Best for clients who want authentication, persistence, and a stronger product feel
- Highest-value handoff package in this line
