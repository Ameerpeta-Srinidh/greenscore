# GreenScore Basic

A beginner-friendly carbon footprint calculator built as a frontend-only React app.

## What Is Included

- Simple React app with 3 carbon input fields
- Instant carbon footprint result with no backend
- Beginner-friendly code structure
- Lockfile included for consistent installs

## Setup

```bash
npm install
npm start
```

Open `http://localhost:5173` in your browser.

## Best Fit

This version is ideal for entry-level buyers, student demos, and quick local presentations where the focus is simplicity instead of backend features.
